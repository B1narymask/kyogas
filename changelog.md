# Kyogas v0.2.0.2
Released 3/9/2026 (DD/MM/YYYY)

# Changes
## Added
- empty keyword (null)
- character escapping 

## Changed
- Strings now require double or single quotes to be valid.
- Improved type checking and overall validation
- now only `t`/`f` and `true`/`false` are valid bools
- key/value pairs are now defined by `:` instead of ` `.
